Putting the site online before I knew any SEO

Before any of the learning can begin, there has to be something real on the internet to learn on — an address that anyone, and any search engine, can visit and read. That is what this site is. It exists first so that everything I want to try next has somewhere to actually happen.

Getting it there took more than I expected. I bought the domain. I wrote the pages by hand, as ordinary HTML and CSS. I set up hosting through GitHub Pages and published the site to it. Then I pointed the domain at that host, so the address I own and the pages I wrote became the same thing.

It is live now, and that is the whole of this first note. The starting line exists; everything after this can be measured against it.
